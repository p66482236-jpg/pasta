# 阀门研习所 · Valve Atlas

面向机械安装现场学习的中英双语阀门图鉴。React + Vite，纯前端运行，无需账户、数据库或 API 密钥。

## 使用

```sh
npm ci --cache /tmp/pasta-npm-cache
npm run dev -- --port 5173
```

生产构建：`npm run build`。预览构建：`npm run preview -- --port 4173`。

无需服务器的离线版：运行 `npm run build:offline`，生成 `downloads/valve-atlas.html`。下载后用 Chrome、Edge、Firefox 或 Safari 打开该 HTML；代码、样式和全部外形图已内嵌，不需要 Node.js 或网络。收藏等本地存储功能取决于浏览器对本地文件的支持；移动或更名文件后原学习记录可能无法沿用。环境内运行的开发服务地址不等于已发布的公网入口。

## 学习功能

- 7 个主要功能分类、32 种常见阀门及结构子类。
- 每条记录包含中英文名称、外形参考、原理示意、口诀、工作原理、识别方法、应用和易混点。
- 中英文搜索、分类筛选、排序、网格与列表视图。
- 收藏、已掌握进度、按章节学习路径，使用浏览器 localStorage 本地保存。
- 10 道随机原理／口诀测验，逐题讲解、结果回顾和最高分记录。
- 手机布局、键盘导航、弹窗焦点约束与减少动画支持。

## 内容与图片说明

内容范围是安装工作常见的阀型与选定子类，不是穷尽全部工业标准的目录。分类按主要学习用途划分，有些结构和用途会交叉。

`public/images/` 的外形图片是 AI 生成的参考插图，**不是现场实拍或厂商产品照片**；网站内已标明。部分内部子类无法凭外形确认。详情原理图为原创简化 SVG，仅用于理解动作关系，并非制造、安装或选型图纸。实际产品的外形、内件、等级、介质兼容性、安装方向与认证应以对应厂家的资料为准。

原始生成图以 4×4 等分图集显示，`src/data.js` 中的 `photo` 字段关联相应单元；安全阀与泄压阀共享同类外形参考。具体学习内容也在该文件维护，简化原理图位于 `src/Diagram.jsx`。

## 验证

```sh
npm run build
npm test
```

测试自动启动独立的临时 Vite 服务，使用系统 Chromium 检查图鉴、筛选、双图切换、收藏持久化、学习进度、完整 10 题测验和多尺寸布局。默认浏览器路径为 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 覆盖；也可通过 `TEST_URL` 指定已有服务。截图保存在 `/tmp/valve-*.png`。
